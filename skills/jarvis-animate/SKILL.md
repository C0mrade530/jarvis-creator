# Jarvis Animate

Сохрани установленный движок проекта и выбранный пользователем визуальный стиль. Если проект новый, выбери по исходникам и формату результата.

- HyperFrames подходит для HTML-композиций и синхронных титров, графики и оверлеев. Прочитай установленный entry skill `hyperframes` и инструкции нужного режима. [Репозиторий HyperFrames](https://github.com/heygen-com/hyperframes)
- Remotion подходит для React-композиций с управлением по кадрам. Прочитай `remotion-best-practices` и руководство для текущей версии проекта. Для распространения учитывай условия лицензии выбранной версии. [Репозиторий Remotion](https://github.com/remotion-dev/remotion)

Если пользователь указал другой репозиторий, проверь точный адрес, назначение, лицензию и инструкции из него. Сохраняй закреплённые зависимости и рабочие источники проекта. Для переноса используемых ресурсов фиксируй их происхождение и разрешённый способ использования.

Для четырёх репозиториев из пакета прочитай [маршруты видео](references/video-repositories.md). Выбирай один подходящий набор по типу результата. Разбор референса, поиск инструментов и рендер являются разными этапами.

Из сценария сделай таймлайн с действиями, входами, смысловыми паузами и выходами. Раздели голос, музыку, текст и графику. Опирайся на измеренную длительность звука, когда он предоставлен. Сцена должна корректно открываться на произвольном кадре. Для новых ассетов используй подготовленные материалы пользователя, оригинальную графику или явно разрешённые ресурсы.

Собери редактируемый исходник, проверь репрезентативные кадры и переходы, затем отрендери согласованный файл при доступном окружении. Проверь геометрию, ритм, читаемость и итоговые потоки видео и аудио. Если пользователь просит только анимацию элемента, передай готовый элемент в указанном формате.
