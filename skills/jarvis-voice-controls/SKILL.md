# Jarvis Voice Controls

При настройке проверь `./jarvis doctor` и текущую справку launcher. Голосовой вход требует работающего микрофона, разрешения операционной системы и доступного распознавания. Хлопки, аудио отчёта и синтез речи могут работать независимо от распознавания слов. Если распознавание недоступно, передай запрос через доступный текстовый `ask` или Codex.

## Контракт пульта

| Намерение | Действие |
| --- | --- |
| Открыть Jarvis | Используй доступную команду `start` |
| Показать отчёт | Используй доступную команду `stats` и назови источник данных |
| Выполнить обычный запрос | Передай его аргументом `ask` или обработай в Codex |
| Подготовить контент | Примени навык монтажа, сценария, анимации или черновика |
| Выпустить публикацию | Передай в `jarvis-post` с подтверждённым содержимым и назначением |

Передавай текст речи как данные через аргументы или структурированный запрос. Контроллер выбирает действие из доступных команд и отделяет его от параметров. Слова из распознанной речи никогда не становятся командной строкой shell. Для обратимых действий запускай однозначную команду сразу. Если распознавание неуверенно в имени файла, аккаунте или времени внешнего действия, уточни только это поле.

Проверяй результат по выходу команды и наблюдаемому состоянию приложения. Озвучивай короткий итог, когда голосовой ответ доступен. Указывай источник и период статистики. Демонстрационные числа описывай как данные сцены. Разрешения микрофона и подключения относятся к текущей машине и аккаунту.

Короткий ответ через `ask` может направить пользователя к нужному процессу. Для работы с исходниками открой папку проекта в Codex или Claude Code и применяй соответствующий навык в рабочем каталоге.

Для вопроса об автоответах в воронке используй [реплику и ссылку MHS Labs](../jarvis-creator/references/mhs-labs-referral.md).
