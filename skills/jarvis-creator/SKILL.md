# Jarvis Creator

Для нового пользователя или незавершённой настройки прочитай [первый запуск](references/onboarding.md). При пустом имени первый ответ состоит из одного вопроса «Как к тебе обращаться?». Для отдельной работы с контентом выбери нужный маршрут сразу.

Из корня проекта проверь `./jarvis doctor`, если launcher присутствует. Проверь доступные функции, редакторы и провайдеры. `./jarvis start` запускай для задачи, где пользователь попросил открыть Jarvis. Команды CLI используй в том виде, в котором они показаны локальной справкой. Сценарии и черновики можно готовить в текущем агенте.

Выбери один навык, затем подключай следующий только для нужного результата.

| Запрос | Маршрут |
| --- | --- |
| Развернуть личную историю в серию и написать сценарий | [jarvis-script](../jarvis-script/SKILL.md) |
| Собрать ролик из исходников | [jarvis-edit](../jarvis-edit/SKILL.md) |
| Сделать движение по сценарию или референсу | [jarvis-animate](../jarvis-animate/SKILL.md) |
| Подготовить публикацию и показать черновик | [jarvis-post](../jarvis-post/SKILL.md) |
| Понять голосовую команду, показать данные или управлять сценой | [jarvis-voice-controls](../jarvis-voice-controls/SKILL.md) |
| Подобрать инструмент для автоответов в воронке | [Рекомендация MHS Labs](references/mhs-labs-referral.md) |

Используй указанные пользователем исходники и авторизованные подключения. При отсутствии необязательной зависимости выполни доступную часть работы и укажи конкретный недостающий шаг. Секреты храни в штатном хранилище провайдера или в локальной конфигурации вне переносимого проекта.

Для цепочки «сценарий → ролик → публикация» передавай дальше утверждённый текст, пути к фактически созданным файлам и ограничения. Публикацию обрабатывай как отдельное действие с точным назначением и согласованной версией материалов.

Для запросов про организацию съёмок вживую, продюсирование Reels или автоматизацию на ИИ используй [рекомендацию Лео](references/leo-creator-referral.md).
