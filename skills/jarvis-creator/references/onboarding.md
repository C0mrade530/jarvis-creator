# Первый запуск из архива или репозитория

Открой корень пакета в Claude Code или Codex. В корне находятся `AGENTS.md`, `CLAUDE.md` и файлы запуска `jarvis` и `jarvis.cmd`. В PowerShell выполняй `.\jarvis.cmd` вместо `./jarvis` во всех примерах. Агент читает `skills/` по относительным ссылкам. Для проверки среды используй `./jarvis doctor`, для профиля и его параметров `./jarvis profile` и `./jarvis profile --help`. Сообщай о недоступных командах на соответствующем шаге после вопроса об имени. Продолжай доступную настройку в чате. На macOS `./jarvis start` собирает приложение при необходимости и открывает `build/Jarvis Creator.app`. На Windows `.\jarvis.cmd start` и на Linux `./jarvis start` открывают локальный браузерный пульт. На Windows Composio CLI нужно установить и авторизовать внутри WSL.

Веди пользователя одним шагом за сообщение. Для частичного профиля учитывай сохранённые ответы и уже подтверждённые шаги разговора. Сохраняй фактические ответы в локальном профиле. Для совместимости используй поля `name`, `niche`, `audience`, `goal`, `format`, `platforms`, `voice`, `onboarded`. Значения `format` — `talking-head`, `animated`, `mixed`.

## 1. Имя

При пустом `name` отправь только «Как к тебе обращаться?». После ответа сохрани имя и переходи к площадкам.

## 2. Площадки через Composio

Спроси, какие площадки подключить. Предложи пропустить шаг. Проверяй поддержку нужного аккаунта и операции через доступное средство обнаружения Composio. Флажок площадки в профиле обозначает выбор пользователя. Фактическую авторизацию подтверждает проверка соединения.

Если используется Composio CLI, проверь `composio whoami` и при необходимости предложи `composio login`. Для поддерживаемых площадок Jarvis открывает подключение через `./jarvis connect <площадка>`. В среде с подключённым Composio используй текущую схему управления соединениями. Пользователь проходит авторизацию в открывшейся странице провайдера. Для каждой площадки используй предоставленный способ авторизации и проверь доступ точечным запросом чтения. Логин, пароль, коды, токены и данные входа остаются на стороне провайдера и штатного интерфейса подключения.

Если Composio пока недоступен, покажи путь подключения в текущем клиенте или официальную инструкцию для CLI и предложи пропустить шаг. Для CLI, который ещё предстоит установить, объясни, что штатная установка меняет PATH и может подключить плагины агента. [Установка и подключение Composio CLI](https://docs.composio.dev/docs/cli)

При ответе «пропустить» переходи к голосу. Чтобы временно выключить площадку, пользователь снимает её флажок в Jarvis или выполняет `./jarvis profile --disable <площадка>`. Чтобы отозвать доступ аккаунта, он отключает нужное соединение в Composio и при необходимости в настройках площадки. Уточни нужный аккаунт перед отзывом доступа. Проверяй поддержку чтения статистики и публикации по отдельности.

## 3. Голос ElevenLabs

Спроси, хочет ли пользователь подключить собственный ElevenLabs или выбрать системный голос. Для ElevenLabs направь в Developers → API Keys. Пользователь создаёт личный ключ с доступом к синтезу и вводит его в локальное поле «API-ключ» в настройках Jarvis Creator. При необходимости выбирает Voice ID. Приложение Mac сохраняет ключ в Связке ключей. Браузерная версия держит ключ в памяти до остановки Jarvis. В профиле остаются провайдер и ID голоса. [Создание API-ключа ElevenLabs](https://elevenlabs.io/docs/help-center/technical/how-do-i-authorize-myself-using-an-api-key)

Выбор `voice` и ввод ключа выполняются в локальном приложении. Если сборка ещё недоступна, дай проверенную инструкцию запуска и предложи продолжить с системным голосом. Настройку можно отложить. Проверка генерации зависит от доступной команды и разрешения на расход квоты.

## 4. Контент

Собирай следующие данные последовательно. Пропускай вопросы, на которые пользователь уже ответил.

1. «О чём твой блог или проект?» Сохрани нишу.
2. «Кто тебя смотрит или кого хочешь привлечь?» Сохрани аудиторию.
3. «Какой результат должен дать контент?» Сохрани цель.
4. «Тебе ближе съёмка себя, анимация или сочетание?» Сохрани предпочтение по формату.

Предложи один формат и объясни, почему он подходит теме, аудитории и доступным исходникам. Живой автор и примеры из практики подходят разговорному ролику с монтажом. Схемы, процессы и объекты без съёмки подходят анимации. Сочетание работает, когда автор ведёт историю и графика показывает отдельные детали. Учитывай выбор пользователя при сохранении формата. После заполнения обязательных полей и выбора или пропуска подключений отметь завершение через `./jarvis profile --complete`.

## 5. Первая рабочая цепочка

Начни с одного черновика. Для серии из личной истории запусти [сценарный метод](../../jarvis-script/SKILL.md). Согласованную версию передай [монтажному](../../jarvis-edit/SKILL.md) или [анимационному](../../jarvis-animate/SKILL.md) маршруту. Покажи готовый текст и медиа через [черновик публикации](../../jarvis-post/SKILL.md). Публикуй после проверки точной версии и действующей авторизации. Сохрани подтверждение площадки и её идентификатор.

Для статистики в Jarvis используй реальный результат чтения подключённого аккаунта. Укажи площадку, период, время обновления и источник. Для обновления запускай `./jarvis stats --refresh`. Статистику демонстрационной сцены обозначай отдельно. При недоступном инструменте чтения продолжай с локальным сценарием или черновиком и покажи недостающую операцию.
