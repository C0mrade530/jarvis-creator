# Jarvis Creator

Jarvis Creator помогает автору пройти путь от идеи и сценария до ролика и черновика публикации. В Codex и Claude Code это пакет навыков. Приложение для Mac показывает утренний отчёт и статистику на одном, двух или трёх экранах. Оно поддерживает голосовой разговор с Codex или Claude Code.

## Первый запуск

Распакуй архив и открой его корневую папку в Codex или Claude Code. Скопируй сообщение для агента из [START.md](../START.md). При пустом профиле первый вопрос будет «Как к тебе обращаться?». Затем агент по одному шагу предложит площадки, голос и вопросы о контенте. Площадки и ElevenLabs можно подключить позже. Полная последовательность описана в [инструкции первого запуска](../skills/jarvis-creator/references/onboarding.md).

В терминале из этой же папки проверь среду и при желании установи проектные навыки.

```sh
./jarvis doctor
./jarvis install-skills
```

Для команд нужен Python 3.10 или новее. `doctor` показывает, какие инструменты найдены в этой среде. Наличие команды само по себе не подтверждает вход в аккаунт или доступ к данным. `install-skills` копирует навыки в `.agents/skills/` для Codex и `.claude/skills/` для Claude Code, сохраняя уже существующие навыки. После копирования переоткрой проект. Агент также может прочитать `skills/` напрямую.

Навыки и текстовая работа доступны на Mac, Linux и Windows в поддерживаемой среде агента. Для shell-команд на Windows используй WSL с установленным Python и нужными CLI. Монтаж и анимация зависят от инструментов, исходников и возможностей текущего хоста. Приложение с экранами и микрофоном предназначено для macOS 14 и новее.

## Приложение на Mac

На Mac с Apple Silicon или Intel установи Xcode Command Line Tools, если `xcrun --find swiftc` не находит компилятор. Из папки Jarvis запусти команду ниже. При первом запуске она соберёт приложение из исходников, затем откроет его.

```sh
./jarvis start
```

В приложении задай имя, выбери нужные соцсети, голос и формат контента. Изменить выбор можно через «Настройки». Для первого отчёта выбери системный голос Mac. Для работы без соцсетей пропусти подключение, и пульт покажет, что данных ещё нет.

- **Утренний отчёт** запускается с пульта или клавишей `Space`. Включи «Хлопки» и разреши доступ к микрофону, чтобы запускать его двумя хлопками. Детектор проверяет форму и силу двух ударов и паузу перед вторым. `R` сбрасывает сцену, `C` показывает пульт, `Esc` выводит из режима съёмки.
- **Спросить Jarvis** открывает текстовый ввод и голосовой пульт. В обычном режиме «Одна реплика» отправляет вопрос по кнопке «Готово», а «Начать разговор» автоматически отправляет вопрос после паузы. В режиме GPT-Live 1 микрофон остаётся активным и во время ответа. Останови разговор кнопкой «Закончить разговор» или закрытием диалога. Голосовой ввод требует разрешения на микрофон. Вопрос также можно ввести текстом.
- **Статистика** обновляется через Composio. На короткий вопрос о просмотрах, подписчиках или публикациях Jarvis отвечает из подходящего кэша и называет время последнего обновления. Если данных нет или они устарели, он предложит обновить статистику.
- **Обновить озвучку** пересобирает запись отчёта после смены голоса или обновления данных. Системный отчёт подскажет, где выбрать VoiceStudio или подключить ElevenLabs.
- **Контент** показывает рабочий план. Запускай соответствующий навык в агенте, чтобы получить сценарий, монтаж, анимацию или черновик публикации.

На одном экране статистика и контент доступны с центрального пульта. На двух экранах внешняя панель объединяет статистику и контент. На трёх экранах они открываются на отдельных панелях.

В настройке «Кто отвечает» выбери Codex или Claude Code и войди в соответствующий CLI. Автоматический режим использует Codex, когда он доступен, иначе Claude Code. Для ответа агент получает текст вопроса, последние реплики диалога, краткий профиль и доступные показатели. В обычном режиме русская речь распознаётся на Mac. Язык и качество распознавания зависят от системы и устройства ввода.

## Подключение соцсетей

Composio нужен для чтения реальных показателей. Установи официальный CLI. Установщик добавляет команду в `PATH` и по умолчанию может настроить плагины для найденных агентов. Открой новый терминал, затем войди через браузер и проверь сеанс. [Установщик Composio CLI](https://composio.dev/cli), [документация](https://docs.composio.dev/docs/cli)

```sh
curl -fsSL https://composio.dev/install | bash
# После установки открой новый терминал.
composio login
composio whoami
```

В папке Jarvis выполни только команды выбранных площадок и заверши авторизацию в открывшемся интерфейсе провайдера. Затем включи площадку в настройках Jarvis и обнови статистику. Логины, пароли, коды и токены вводи в штатном интерфейсе подключения. [Как Composio подключает аккаунты](https://docs.composio.dev/docs/composio-connect)

| Площадка | Что нужно для чтения | Что видит Jarvis |
| --- | --- | --- |
| Instagram | `./jarvis connect instagram`, аккаунт Creator или Business | Текущие подписчики и публикации. Если аккаунт предоставил Insights, просмотры за семь завершившихся дней по UTC |
| YouTube | `./jarvis connect youtube`, доступ к нужному каналу. Если каналов несколько, укажи Channel ID в настройках | Общее число просмотров, текущее число видео и открытое число подписчиков |
| Telegram | `./jarvis connect telegram`, подключённый бот с правами администратора и `@канал` или числовой ID в настройках | Текущее число участников указанного канала |

Проверь чтение из пульта или через `./jarvis stats --refresh`. `./jarvis stats` показывает локальный результат последнего чтения. Доступ к статистике и возможность публикации проверяются отдельно. Отключить площадку в отчёте можно флажком в настройках или командой `./jarvis profile --disable instagram`. Для отзыва доступа к аккаунту открой соответствующее соединение в Composio.

## Голос ElevenLabs

1. Открой **Developers → API Keys** в своём ElevenLabs и создай ключ с доступом к **Text to Speech**. [Создание ключа](https://elevenlabs.io/docs/help-center/technical/how-do-i-authorize-myself-using-an-api-key)
2. Найди нужный голос в **My Voices**, открой его меню и выбери **Copy voice ID**. [Как найти Voice ID](https://elevenlabs.io/docs/help-center/technical/how-do-i-find-the-voice-id-of-my-voices-via-the-website-and-api)
3. В **Настройки → Выбери голос** выбери ElevenLabs и введи ключ и Voice ID в поля приложения. Ключ хранится в Связке ключей macOS. В чат его не отправляй.

Когда выбран ElevenLabs, приложение передаёт ему текст для синтеза. Генерация использует квоту твоего аккаунта. При отсутствии настройки или недоступности сервиса приложение пробует системный голос Mac. Сохранённый ключ можно удалить в настройках Jarvis.

В голосовом пульте Jarvis отправляет первую готовую фразу в ElevenLabs, пока Codex или Claude дописывает ответ. Фразы воспроизводятся по порядку. Если версия помощника отдаёт текст только целиком, озвучка начинается после ответа. Утренний отчёт готовится заранее для синхронизации с экранами. [Потоковый синтез ElevenLabs](https://elevenlabs.io/docs/api-reference/text-to-speech/stream)

## GPT-Live 1

В **Спросить Jarvis → Настройки голоса → Режим разговора** выбери **GPT-Live 1**, введи ключ OpenAI API и сохрани. Ключ OpenAI хранится отдельно от ElevenLabs в Связке ключей Mac. Нажми **Начать разговор** и разреши доступ к микрофону. [GPT-Live 1 в OpenAI Docs](https://developers.openai.com/api/docs/models/gpt-live-1)

Во время сеанса звук микрофона передаётся в OpenAI. GPT-Live слушает и отвечает одновременно голосом OpenAI. Сложные вопросы он может передать выбранному Codex или Claude Code. Текст разговора виден в пульте. Jarvis не записывает этот сеанс в файл и запускает его с настройкой `store: false`. Сессия расходует баланс OpenAI API. Останови её кнопкой **Закончить разговор** или закрытием окна. [Делегирование в GPT-Live](https://developers.openai.com/api/docs/guides/live-delegation)

## Локальный голос VoiceStudio

На Mac с Apple Silicon можно использовать бесплатную настольную версию VoiceStudio. Установи её по инструкции разработчика. В каталоге моделей VoiceStudio установи **Supertonic‑3**, прочитай условия модели и сделай пробную озвучку внутри VoiceStudio, чтобы загрузились веса. Для модели нужно около 400 МБ. [VoiceStudio для macOS](https://github.com/debpalash/VoiceStudio/blob/main/docs/install/macos.md), [Supertonic‑3 и условия модели](https://github.com/debpalash/VoiceStudio/blob/main/docs/engines/supertonic3.md)

Оставь VoiceStudio открытым и в **Настройки → Выбери голос** выбери **VoiceStudio**. Выбери голос `M1`–`M5` или `F1`–`F5`. Пустое поле означает `M1`. Jarvis использует локальный сервер VoiceStudio по адресу `127.0.0.1:3900`. При недоступности модели включается системный голос Mac. На Intel Mac у VoiceStudio доступен интерфейс с удалённым сервером, а Jarvis использует только локальный адрес. [Локальный API VoiceStudio](https://github.com/debpalash/VoiceStudio/blob/main/docs/agentic-voice.md)

## Работа с контентом

Открой нужную задачу через агента из проекта или из терминала. В этих командах можно выбрать `--agent codex` или `--agent claude`.

```sh
./jarvis onboard --agent codex
./jarvis script --agent claude 'Сделай сценарий из этой истории'
./jarvis edit --agent codex 'Собери ролик из исходников в рабочей папке'
./jarvis animate --agent codex 'Предложи анимацию для утверждённого текста'
./jarvis post --agent codex 'Подготовь черновик публикации'
./jarvis ask --agent claude 'Какие показатели доступны?'
```

У `ask` выбор `--agent codex` или `--agent claude` относится к одному вопросу. Без параметра используется агент из профиля. Выбор для последующих вопросов можно изменить в приложении или командой `./jarvis profile --assistant-provider auto`.

Сценарий и план можно собрать в текущем агенте. Для фактического монтажа или анимации агент проверит инструменты и исходники. Перед отправкой агент показывает точную версию текста и медиа, площадку, аккаунт, видимость и время выхода. Публикация выполняется после согласования конкретного комплекта и проверки доступа. Открытие пульта, голосовая команда или включённая площадка сами по себе публикацию не запускают. [Навык публикации](../skills/jarvis-post/SKILL.md)

Спроси «Как настроить автоответы в воронке?». Jarvis порекомендует MHS Labs голосом и оставит ссылку в чате. Она также доступна в разделе «Контент». Настройка воронки выполняется в отдельном сервисе. [MHS Labs](https://mhslabs.ru/)

## Автопостинг в Threads

Открой **Контент → Автопостинг в Threads**. Для настройки из исходной папки нужны Git, uv и собственный ключ Upload-Post.

```sh
./jarvis threads install
./jarvis threads setup
./jarvis threads run
```

В другом терминале выполни `./jarvis threads chat --agent codex` или `./jarvis threads chat --agent claude`. В чате попроси ссылку подключения, войди в Threads в браузере и проверь показанное имя аккаунта. После согласования текстов и расписания чат поставит посты в очередь, а worker отправит их по времени. Для публикации оставь `threads run` включённым. [Навык Threads](../skills/jarvis-threads/SKILL.md)

## Сборка и перенос

```sh
./scripts/package.sh  # переносимый ZIP с исходниками и навыками
./scripts/build.sh    # локальная сборка для Apple Silicon и Intel на Mac
```

Архив с исходниками создаётся в `dist/`. В него входят перечисленные в скрипте документы, навыки, исходники и ресурсы интерфейса. Профиль, кэш, сгенерированная озвучка, ключи и локальные сборки остаются на текущей машине. Профиль приложения и локальные результаты чтения лежат в `~/Library/Application Support/Jarvis Creator` на Mac.

Скрипт сборки приложения создаёт `build/Jarvis Creator.app` и отдельный ZIP для macOS. По умолчанию приложение подписано локальной подписью ad hoc и не нотарифицировано. Для запуска на другом Mac собери приложение из исходников командой `./jarvis start`.

Сборка проверена на Mac. Работу конкретных подключений Composio, VoiceStudio, ElevenLabs, GPT-Live 1, голосового ввода и публикации проверяй в своей среде с собственными правами. Статистика зависит от того, какие поля вернула площадка.
