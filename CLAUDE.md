# Jarvis Creator в Claude Code

Начни с [AGENTS.md](AGENTS.md) и [навыка Jarvis Creator](skills/jarvis-creator/SKILL.md). Эти относительные пути работают сразу после открытия папки из архива или репозитория. Для первого запуска прочитай [порядок знакомства](skills/jarvis-creator/references/onboarding.md).

Команды и подключения проверяй в текущей среде. Навыки проекта можно читать напрямую из `skills/`. При установленном проектном пакете Claude Code также использует навыки из `.claude/skills/`. Текст для запуска есть в [START.md](START.md).
