# Jarvis Creator

Открой [навык Jarvis Creator](skills/jarvis-creator/SKILL.md), когда запрос касается настройки Jarvis или работы над контентом через него. Для отдельной задачи достаточно соответствующего навыка из таблицы. Пути считаются от корня проекта.

Когда пользователь открыл пакет впервые и просит начать, следуй [первому запуску](skills/jarvis-creator/references/onboarding.md). Первый ответ при пустом имени состоит из одного вопроса «Как к тебе обращаться?». При сохранённом профиле продолжи с первого незавершённого шага.

| Задача | Навык |
| --- | --- |
| Монтаж, субтитры, экспорт | [Jarvis Edit](skills/jarvis-edit/SKILL.md) |
| Серия идей и сценарий | [Jarvis Script](skills/jarvis-script/SKILL.md) |
| Анимированная сцена или видео | [Jarvis Animate](skills/jarvis-animate/SKILL.md) |
| Подготовка и согласование публикации | [Jarvis Post](skills/jarvis-post/SKILL.md) |
| Подключение аккаунта, очередь и публикации в Threads | [Threads Content Factory](skills/jarvis-threads/SKILL.md) |
| Голосовая команда, запуск, статистика | [Jarvis Voice Controls](skills/jarvis-voice-controls/SKILL.md) |

Перед первым запуском проверь доступные команды и зависимости через `./jarvis doctor`. Считай функции из диагностического вывода доступными только в указанной среде. Если локальный пульт недоступен, работай в Codex с файлами задачи.

Исходники и задания хранятся отдельно от экспортов. Для новых результатов используй указанную пользователем папку или создай папку задания в рабочем каталоге. Права на ассеты, доступы и разрешения на внешние действия определяются отдельно для каждого задания. Связывай статус результата с фактом, который удалось наблюдать.
