Как к тебе обращаться?

Jarvis будет использовать это имя в утреннем отчёте.

Подключи свои соцсети

Установи Composio CLI по инструкции в README и выполни composio login. Включай только те площадки, которые хочешь видеть.

./jarvis connect instagram

Подойдёт аккаунт Creator или Business.

./jarvis connect youtube
./jarvis connect telegram

Для счётчика участников добавь подключённого бота администратором канала.

Команды выполняются в папке Jarvis Creator. Доступ выдаётся на странице Composio. Можно пропустить этот шаг.

Выбери голос и помощника

Системный голос Mac подойдёт для первого запуска. Для более естественной озвучки подключи ElevenLabs или запусти VoiceStudio на Mac с Apple Silicon.

  1. В ElevenLabs открой Developers → API Keys и создай ключ с доступом к Text to Speech.
  2. В Voices открой меню выбранного голоса и скопируй Voice ID.
  3. Вставь оба значения в поля ниже.

Открой VoiceStudio, загрузи Supertonic 3 и запусти локальный API на порту 3900. Инструкция и ссылка есть в README.

Войди в выбранном CLI на этом Mac. В режиме «Автоматически» Jarvis использует Codex, если он установлен, иначе Claude Code.

Во время разговора GPT-Live получает звук микрофона и отвечает голосом OpenAI. Для сложных вопросов используется выбранный помощник. Сессия расходует баланс OpenAI API.
