# Первый запуск Jarvis Creator

Распакуй архив или открой папку репозитория в Claude Code или Codex. Рабочим каталогом выбери папку с `AGENTS.md` и launcher `jarvis`.

Вставь это сообщение агенту.

> Открой AGENTS.md и skills/jarvis-creator/SKILL.md. Помоги мне с нуля настроить Jarvis Creator по инструкции первого запуска. Если профиль пустой, задай только вопрос «Как к тебе обращаться?». Дальше веди меня по одному шагу за раз.

Для автоматического обнаружения навыков в открытом проекте выполни `./jarvis install-skills` и переоткрой папку. Команда копирует навыки в `.agents/skills/` для Codex и `.claude/skills/` для Claude Code.
